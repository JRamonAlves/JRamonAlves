# José Ramon Severo Alves

Computer Science student at the Federal University of Campina Grande, Brazil. I focus on full-stack development, backend services, and tools that make development easier.

I contribute to university R&D projects in partnership with VTEX. My work includes React chart components and backend architecture for a server-driven UI prototype, alongside testing, code review, and developer workflows.

## Projects

### [Mimo Secreto](https://www.mimosecreto.app)

A product for organizing private Secret Santa exchanges. I develop both the React and TypeScript frontend and the NestJS and PostgreSQL backend.

### [RHS Rust](https://github.com/JRamonAlves/rhs-rust)

A Rust and Axum API for finding home-lab services and sharing text between my devices, with Redis storage and generated OpenAPI documentation. I use the service through a private Tailscale network; the public repository contains the backend with sample configuration.

### [Agent workflow tools](https://github.com/JRamonAlves/skills)

My configuration for agent-assisted development. I select and adapt skills and build shell installers and Git hooks to keep them synchronized. Bundled skills include work from Matt Pocock and Vercel.
